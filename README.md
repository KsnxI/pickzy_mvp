#Что делает приложение: 
Небольшое приложение для поиска мест по городу с возможностью регистрации, входа и фильтрации мест

#стек
-Python(backend)
-React(frontend)
-SQLlite(DB)
-FastAPI

#Локальный запуск проекта:
Через папку backend: python -m uvicorn app.main:app --reload   
Через папку frontend: npm run dev

#как остановить 
control+C в двух папках
